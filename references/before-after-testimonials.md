# ビフォーアフター・体験談・症例写真の取扱い

化粧品広告で最もリスクが高い領域。安易に使うと医薬品的効能の暗示と判定される。

---

## 1. 化粧品でのビフォーアフター写真

### 原則

化粧品では、効能を超える視覚的訴求になりやすいため、**ビフォーアフター写真は原則として強い規制対象**。

### NGの典型

- シミ・ソバカスが消えたかのような前後比較
- シワが減った/なくなった印象を与える前後比較
- 肌全体の色調が劇的に変わって見える前後比較
- 加工・補正・照明調整による効果の誇張
- メーキャップ効果と化粧品効果を混同させる前後比較
- 異なる時間帯・異なる化粧の有無での撮影
- 角度・距離・表情の差異を利用した印象操作

### 限定的に許容されうるケース

- メーキャップ効果としての前後比較で、「**メーキャップ効果により**」の併記がある
- 56効能内の効果（保湿によるツヤ・キメ）であることが明確
- 同一条件（照明・カメラ設定・時間帯）での撮影が証明できる
- 加工なしの旨が明示されている
- 試験データに基づく場合は、試験条件・方法の併記

### 「乾燥による小ジワを目立たなくする」での前後比較

- 効能評価試験ガイドラインに従った試験データが必須
- 表示する場合は試験条件・方法の併記が必要
- 試験以外のサンプル写真（個人の使用後写真など）の使用はNG
- 「効能評価試験済み」の記載と試験データの保有が必須

## 2. 施術ビフォーアフター（サロン・クリニック文脈）

### 施術効果と化粧品の効果は分けて記述する

- サロン施術（マッサージ、機器使用）の効果と化粧品単体の効果を混同しない
- 「サロン施術の前後」を「化粧品の効果」と読まれる構成は避ける
- 施術と化粧品をセットで訴求する場合も、それぞれの寄与を明確に

### あはき法・医師法との関係

- マッサージ的施術の効能訴求は、あん摩マッサージ指圧師法・医師法に抵触するリスク
- 「リフトアップ」「肩こり改善」「血行促進」等の身体機能改善訴求は医療類似行為と評価されうる
- サロンが「治療」「症状改善」「医療効果」を訴求すると医師法違反のリスク
- 医療類似行為の暗示（脱毛、シミ取り等）は無資格営業として摘発される事例あり

### サロン経由販売時の注意

- サロン店頭POPやスタッフ説明資料が「事業者の表示」と評価されうる
- メーカーが提供する販促物の表現はメーカー責任
- サロン独自作成の販促物にも、メーカーは管理責任を負う可能性

## 3. 体験談の取扱い

### 化粧品広告ガイドライン（医薬品等適正広告基準）

体験談は以下を満たす必要がある:

- **56効能の範囲内**である
- 効果保証になっていない
- 個人の感想である旨の明記
- **使用者・撮影日・撮影条件**が明確（写真使用時）
- ステマ規制への対応（謝礼の有無の透明性）

### 推奨される体験談の作り方

✅ OKな例:
> 「乾燥が気になる季節でも、しっとり感が続いて肌の調子がいいです」（個人の感想です。効果には個人差があります）

> 「メイクのノリが良くなった気がして、嬉しいです」（個人の感想です。効果には個人差があります）

> 「香りに癒されて、毎日のスキンケアが楽しみになりました」

🔴 NGな例:
- 「3日でシミが薄くなりました!」← 効能逸脱、即効性訴求
- 「皮膚科に行っても治らなかった肌荒れが治った」← 医薬品的効能訴求
- 「20歳若返ったと言われます」← 若返り訴求
- 「鏡を見るたびに肌が明るくなっていく」← 美白訴求
- 「これ一本で全ての悩みが解決」← 万能訴求

### 体験談取得時の注意

- **謝礼の有無を記録**（ステマ規制対応）
- **書面同意**（個人情報保護法・著作権・肖像権）
- **誘導的設問を避ける**（景表法・優良誤認）
- 一定割合のネガティブ・中立意見も含めた選定（恣意的な抽出は優良誤認のリスク）
- 撮影条件の統一性（時間帯、照明、メイクの有無）

## 4. インフルエンサー・アンバサダーへの依頼

### ステマ規制対応（2023.10〜）

依頼投稿には必ず以下を実施:

- 「#PR」「#広告」「#プロモーション」等を投稿の冒頭・目立つ位置に明示
- 「#アンバサダー」「#〇〇モニター」だけでは不十分とされる場合あり
- 投稿前のチェック体制（事業者として誇大表現を黙認しない）
- 契約書に表記義務を明記
- 不適切表現の差替え・削除依頼体制

### アフィリエイトでの責任

事業者がアフィリエイト記事に関与している場合（紹介料を支払う、原稿を確認する等）、記事内容も事業者の表示として景表法適用対象。

- アフィリエイターの誇大表現も事業者責任
- ASP・アフィリエイターとの契約に表現規制条項
- 定期巡回と是正措置の記録保持

## 5. 症例写真（医療類似領域）

サロン・エステ業態でよくある「肌改善症例」「フェイシャルビフォーアフター」は、

- 化粧品の効能を超える訴求に該当しやすい
- 医療類似行為（医師法違反）と評価されるリスク
- ステマ規制・景表法・薬機法の三重リスク

原則使用を避けるか、**専門家確認を経た上で限定的に使用**すること。

## 6. SNS投稿での実務的なガイドライン

### Instagram

- 投稿冒頭に「#PR」等を明示（キャプション末尾やコメント欄での記載は不十分）
- ストーリーズでの「#PR」は十分な視認時間と位置で
- ハッシュタグでの効能訴求(#若返り 等)もNG表現の対象

### TikTok

- 動画内テロップでのPR表記
- 短尺ゆえの誇大表現リスク（一発のインパクトを狙うため）

### YouTube

- 概要欄での「広告」表記だけでなく、動画冒頭での口頭・テロップ明示推奨
- 長尺ゆえの体験談的展開が効能逸脱になりやすい

### X (旧Twitter)

- 文字数制限内での効能逸脱に注意
- リツイート・引用RTでもメーカーの管理対象となりうる

## 7. 監査用チェックリスト

公開前のビフォーアフター・体験談コンテンツに以下を当てる:

- [ ] 56効能を超える効果訴求がないか
- [ ] 「個人の感想です」の併記があるか
- [ ] 撮影条件（照明・時間・メイク）が統一されているか
- [ ] 画像加工がないことが確認できるか
- [ ] 謝礼の有無を記録しているか
- [ ] 書面同意を取得しているか
- [ ] ステマ規制対応（#PR等）が適切か
- [ ] 試験データに基づく訴求の場合、データの保有・併記があるか
- [ ] 施術効果と化粧品効果を混同していないか
- [ ] 医療類似行為の暗示がないか
