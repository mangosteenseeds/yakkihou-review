# 化粧品の効能の範囲（56効能効果）

出典: 平成23年7月21日厚生労働省医薬食品局審査管理課長通知「化粧品の効能の範囲の改正について」（薬食審査発0721第1号）

一般化粧品で表示可能な効能は以下の **56項目** に限定される。これ以外の効能訴求は薬機法違反となる。

> **重要な注意**: これら56効能の範囲内の表現であっても、他の語句と組み合わせることで医薬品的効能を暗示すれば違反となる（例: 「肌を整え若返る」）。前後の文脈・全体の構成を含めて評価すること。

## 特殊（55〜56）

### 55. 乾燥による小ジワを目立たなくする。（効能評価試験済み）

- ⚠️ **抗シワ効能評価試験ガイドライン**に従った試験データが必須
- 試験データなしで使用するのは薬機法違反
- 「シワを消す」「シワがなくなる」「アンチエイジング(シワ消失)」はNG（効能を超える）
- 表現上の注意: 「乾燥による小ジワを目立たなくする(効能評価試験済み)」と注記を入れる運用が一般的

### 56. メーキャップ効果により〇〇する

物理的なメーキャップ効果（色調を変える、顔色を明るく見せる、立体感を与える、シミ・ソバカス・くすみ・赤みなどをカバーする等）に限定。

- ⚠️「**メーキャップ効果により**」の文言を必ず併記すること
- 物理的な化粧効果に限定。肌そのものの変化を訴求する表現はNG
- 例: 「メーキャップ効果によりシミをカバーします」は OK
- 例: 「シミを消します」は NG

## 注意事項

### 56効能の範囲内であっても違反となる例

- 「肌のキメを整える」(20番) は OK だが、「肌のキメを整えて若返ったような肌へ」は若返り訴求として NG
- 「日やけによるシミ、ソバカスを防ぐ」(36番) は OK だが、「シミを防いで透明感のある美白へ」は美白訴求として NG（一般化粧品では「美白」は不可。医薬部外品でも厳格な要件）
- 「皮膚を清浄にする」(17番) は OK だが、「皮膚を清浄にしてニキビを治す」はニキビ治療訴求として NG

### 医薬部外品の場合

医薬部外品は、各製品の承認書に記載された効能効果のみ表示可能。一般的な医薬部外品の効能カテゴリ例:

- 薬用化粧水・乳液: 「肌あれ・あれ性。あせも・しもやけ・ひび・あかぎれ・にきびを防ぐ。油性肌。」等
- 薬用美白化粧品: 「メラニンの生成を抑え、シミ・ソバカスを防ぐ。日やけ・雪やけ後のほてりを防ぐ。」等
- 育毛剤: 「育毛、薄毛、かゆみ、脱毛の予防、毛生促進、発毛促進、ふけ、病後・産後の脱毛、養毛」等

承認書記載の範囲外の効能訴求はNG。「薬用」表記の有無、有効成分の特定、認められた効能の表現範囲を必ず確認すること。

### 「美白」訴求について

「美白」は一般化粧品では原則使用不可。医薬部外品で「メラニンの生成を抑え、シミ・ソバカスを防ぐ」効能が承認された製品でのみ、「美白」「ホワイトニング」等の言葉が使用可能（ただし「シミ・ソバカスが消える」「肌が白くなる」は不可）。
