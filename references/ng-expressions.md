# NG表現データベース

化粧品広告で頻出するNG表現を分類別にまとめる。検出時は法的根拠と修正案を提示する。

> 各表現はあくまで典型例。実際の判定は文脈・前後表現・画像との組合せ・受け手のセグメントを総合して判断すること。

---

## カテゴリA: 医薬品的効能（薬機法66条/68条違反リスク高）

| NG表現 | 問題点 | 修正案（56効能内） |
|---|---|---|
| 治る / 治療する / 治癒する | 医薬品的効能 | 「肌を整える」「健やかに保つ」 |
| 改善する | 効能訴求が強すぎる | 「肌のキメを整える」「すこやかに保つ」 |
| 予防する（疾病・症状） | 医薬品領域 | 疾病予防は不可。「乾燥を防ぐ」など物理的予防のみ可 |
| 効く / 効果がある | 医薬品的効能 | 「うるおいを与える」「肌を整える」 |
| 治癒力 / 回復力 / 再生力 | 身体機能変化 | 削除推奨 |
| 〇〇に効果 / 〇〇に効く | 医薬品的暗示 | 「〇〇のためのケア」「〇〇が気になる方へ」 |
| 美白する / 白くなる | 化粧品では不可 | 「日やけによるシミ、ソバカスを防ぐ」（要医薬部外品） |
| ニキビが治る | 医薬品的効能 | 「（洗浄により）ニキビを防ぐ」（洗顔料に限る） |
| アトピーに効く / アレルギー改善 | 疾病訴求 | 削除必須 |
| 育毛 / 発毛 | 医薬部外品/医薬品領域 | 化粧品では不可。「頭皮、毛髪をすこやかに保つ」 |
| 抗炎症 / 鎮静 | 医薬品的効能 | 「肌を整える」 |
| 殺菌 / 除菌（皮膚への） | 医薬部外品領域 | 「皮膚を清浄にする」 |
| デトックス / 毒素排出 | 身体機能訴求 | 削除推奨 |
| 解毒 / 浄化（生理的意味で） | 医薬品的効能 | 「皮膚を清浄にする」(物理的意味のみ) |

## カテゴリB: 身体構造・機能の変化を暗示

| NG表現 | 問題点 | 修正案 |
|---|---|---|
| 若返る / アンチエイジング | 加齢による変化を戻す訴求は不可 | 「エイジングケア（年齢に応じたお手入れ）」と注釈付きで使用可 |
| 細胞が活性化 / 細胞を再生 | 身体機能の変化 | 削除必須 |
| 真皮まで届く / 真皮に作用 | 化粧品の作用部位を超える | 「角層まで」のみ可 |
| 奥深く浸透 | 角層を超える暗示 | 「角層まで浸透」と明示 |
| 肌再生 / 肌の生まれ変わりを促進 | ターンオーバー促進訴求は要注意 | 「肌のキメを整える」 |
| シミが消える / シミがなくなる | 効能を超える | 「日やけによるシミ、ソバカスを防ぐ」(医薬部外品) |
| シワがなくなる / シワを消す | 効能を超える | 「乾燥による小ジワを目立たなくする」(試験データ必須) |
| 痩せる / 脂肪燃焼 / セルライト除去 | 身体構造変化 | 削除必須 |
| バストアップ / リフトアップ（物理的変化） | 身体形態変化 | 化粧品では不可 |
| 毛穴が消える / 毛穴がなくなる | 構造変化 | 「肌のキメを整える」 |
| ターンオーバー促進 / 新陳代謝活性化 | 生理機能訴求 | 削除推奨 |
| ヒアルロン酸が増える | 体内成分の変化 | 「うるおいを与える」 |
| コラーゲン生成促進 | 体内成分の変化 | 削除推奨（成分配合の事実のみOK） |
| 血行促進 | 医薬品的効能 | 削除必須 |
| ホルモンバランスを整える | 医薬品的効能 | 削除必須 |

## カテゴリC: 絶対的効果保証

| NG表現 | 問題点 | 修正案 |
|---|---|---|
| 必ず〇〇 / 絶対に〇〇 | 効果保証は不可 | 「〇〇に役立つ」「〇〇のためのケア」 |
| 100% / 完全に / 完璧に | 絶対的訴求 | 削除 |
| 誰でも / 全ての人に | 個人差を否定 | 「多くの方に」「年齢を問わず」(根拠あれば) |
| 即効性 / すぐ効く / 数分で | 即効性訴求は化粧品で不可 | 削除 |
| 永久に / 一生 / 半永久的 | 持続性の絶対訴求 | 削除 |
| 確実に / 保証 | 効果保証 | 削除 |
| 一度で / 一回で〇〇 | 即効性 | 削除 |

## カテゴリD: 最大級表現・序列訴求（景表法も併せて要注意）

| NG表現 | 問題点 |
|---|---|
| No.1 / 第1位 | 客観的調査根拠が必要（調査主体・期間・範囲・対象） |
| 業界最高 / 業界最強 / 究極 | 根拠困難。原則NG |
| 唯一の / 他にない / オンリーワン | 客観的根拠が必要 |
| 世界初 / 日本初 / 世界唯一 | 根拠と「いつ時点」の明示が必要 |
| 圧倒的 / 驚異の / 驚きの | 根拠なき優良誤認 |
| 最先端 / 最新技術 | 根拠なき優位性訴求 |
| 業界をリードする | 根拠困難 |
| ベスト〇〇 / ランキング1位 | 第三者調査の客観性必須 |
| 大ヒット / 爆売れ | 根拠提示が必要 |

## カテゴリE: 安全性の絶対断定

| NG表現 | 問題点 |
|---|---|
| 副作用なし / 安全 / 安心 | 安全性を保証する表現は不可 |
| 自然由来だから安全 / オーガニックだから安心 | 因果関係なし |
| 〇〇フリー / 無添加（範囲不明） | 範囲不明確だと優良誤認 |
| 敏感肌でも安心 / 敏感肌でも使える | 個人差を無視 |
| 赤ちゃんにも使える / 子供にも安心 | 根拠なき断定 |
| 妊婦でも使える | 個別差・医療判断領域 |
| 肌に優しい(根拠なき) | 安全性訴求 |
| アレルギーが出ない | 個人差・断定不可 |
| 低刺激（根拠なし） | パッチテスト等の根拠と表記限定が必要 |

> 「無添加」「〇〇フリー」は具体的に何を含まないか明記が必要。「合成香料無添加」「パラベンフリー」のように対象明示なら使用可能。ただし、「無添加」を理由に安全性を訴求するのはNG。

## カテゴリH: 体験談・口コミの取扱い（景表法）

| NG表現 | 問題点 |
|---|---|
| 「使ったらシミが消えました!」（体験談） | 個人の感想でも効能逸脱の暗示 |
| 「3日で肌が変わった」 | 即効性訴求 |
| 「もう手放せません」（誇張） | 過度な依存性訴求 |
| 「他では絶対に手に入らない」 | 排他性・誇大 |
| 「皮膚科に通っても治らなかったのが治った」 | 医薬品的効能 |
| 「友達に勧めまくっています」 | 紹介誘引 |

> 体験談は56効能の範囲内かつ「個人の感想です。効果には個人差があります」の併記。さらに**ステマ規制**（2023.10〜）でPR表記が必要なケースに注意。

## カテゴリJ: グレーゾーン（要文脈判断）

| 表現 | 判定の考え方 |
|---|---|
| エイジングケア | 「年齢に応じたお手入れ」の注釈があれば可。注釈なく若返り訴求の文脈ならNG |
| ハリ・ツヤ | 56効能内なのでOK。「シワが消える」と組み合わさるとNG |
| 美容液 / セラム | カテゴリ名としてOK |
| ドクターズコスメ | 単なるブランド名としてはOKだが、医療効果暗示があるとNG |
| 肌質改善 | 一般用語としては使われるが「改善」が医薬品的訴求になりうる。要文脈判断 |
| 透明感のある肌 | OK。「美白」と組み合わさるとNG |
| ハリ感アップ | 「ハリ」自体はOK。「リフトアップ」と組み合わさると要注意 |
| 集中ケア | OK。「集中治療」「集中改善」と紛らわしい使い方は要注意 |
| プロ仕様 / サロン仕様 | カテゴリ名としてはOK。効能差を強調するとNG |
| 〇〇研究所開発 | 事実なら OK。医療研究機関と誤認させるとNG |
| 浸透 | 「角層まで浸透」と明示すればOK。「奥深く浸透」「肌の奥まで」はNG |
| 高濃度配合 | 配合事実が正確なら OK。効能訴求と組み合わせると要注意 |
| プレミアム / 最高級 | 主観的・品質感のみなら OK。効能・成分の最高級性ならNG |
| 自然派 / ナチュラル | OK。「だから安全」と組み合わさるとNG |
| 韓国コスメ仕様 / フランス品質 | 産地・スタイル表現として OK |

## カテゴリK: ステマ規制関連（2023.10〜）

| NG / 注意 | 問題点 |
|---|---|
| インフルエンサー投稿で #PR なし | ステマ規制違反 |
| アフィリエイト記事で広告表記なし | 景表法違反（事業者表示として扱われる） |
| 自社社員のレビュー投稿（無記名） | ステマ |
| 商品提供を受けたインフルエンサーが「自腹で買った」表記 | 虚偽 |
| 「#アンバサダー」のみ（#PR や #広告 なし） | 不十分な可能性 |
| 第三者を装ったレビュー記事の発注 | 重大違反 |

## 参考: 違反した場合のリスク

- 薬機法違反: 行政指導、業務停止命令、課徴金、刑事罰（2年以下の懲役または200万円以下の罰金、または併科）
- 景表法違反: 措置命令、課徴金（売上の3%）、公表
- 化粧品メーカー: 製造販売業許可への影響
- レピュテーション: 措置命令は公表されるため、業界・消費者への信頼失墜が大きい
